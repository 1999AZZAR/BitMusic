# Desktop resource optimization: 1.4.0-beta-0

Validated on 2026-11-04, on the Linux KDE Wayland workstation. Work is on `staging`; production remains 1.3.19.

## Measured result

Each cell lists **1.3.19 / 1.4.0-beta-0**. Memory is MiB; CPU is percent of one logical CPU (100% is one fully occupied core). Values are medians, discarding the first five samples of each phase.

| Workload | RSS MiB | PSS MiB | CPU % | Threads |
|---|---:|---:|---:|---:|
| Idle (early startup settled) | 559.6 / 493.0 | 433.3 / 366.4 | 51.16 / 0.00 | 77 / 68 |
| Visible playback | 691.9 / 577.9 | 560.6 / 448.7 | 59.58 / 37.71 | 95 / 73 |
| Hidden playback | 693.7 / 555.7 | 561.0 / 426.5 | 2.98 / 1.99 | 93 / 68 |
| Visible paused | 692.1 / 553.3 | 559.4 / 424.1 | 47.28 / 0.00 | 68 / 57 |
| Hidden paused | 692.0 / 555.1 | 559.3 / 425.9 | 1.97 / 0.00 | 68 / 56 |

Visible playback PSS fell by 20.0%; visible paused PSS fell by 24.2%. Visible playback CPU fell by 36.7%, with the visualizer enabled. Zero CPU entries mean the median was below the sampler's 1-second accounting resolution, not that the process can never wake.

The earlier real user process had 1,264,540 KiB RSS, 1,140,685 KiB PSS and roughly 81 MiB of live Java heap after about an hour. That observation established that a heap-only fix was insufficient. It is **not** the denominator for the reductions above: that process had different browsing/playback history.

## Method and scope

- Both builds use the same full JDK 21 toolchain and host graphics/audio libraries, through AWT/Skiko in the Wayland session.
- A fresh temporary home, preferences, cache, data and state directory prevent changes to the user's account, queue, cache or running instance. Session D-Bus is deliberately disconnected.
- The fixture is a generated local 44.1 kHz stereo WAV, played at zero gain. Network requests go to an unavailable loopback proxy so changing remote recommendations cannot change the workload.
- Default glass UI and visualizer remain enabled. Canvas and autoplay are disabled in both fixtures.
- The 145-second scenario covers startup, visible idle, visible playback, hidden playback, hidden pause, and visible pause. Samples include the Java process and its descendants; build daemons are excluded.
- Startup/early-idle numbers include initial loading/retries. This is not a long-session browsing, streaming, animated-Canvas or cross-platform memory soak test.
- Both sampled runs had one process; the older bundled server could not become a second persistent child while the user's existing server occupied its port. The server's new on-demand lifecycle is verified in code, not claimed as a measured process-count reduction.
- Final app/UI jar names were checked against the Debian archive. Fingerprints and summary measurements are preserved in [the result data](1.4.0-beta-0.json).
- Earlier exploratory online runs and runs using an outdated `createDistributable` output were discarded. `packageDeb` does not refresh that separate profiler input.

## Changes

- A single 24 MiB Coil decoded-image cache replaces the separate desktop cache and default player cache. Decode concurrency is two; displayed images use layout/request size. No runtime dependencies were added.
- Initial JVM heap is 32 MiB, maximum heap 384 MiB; G1 can return spare heap. JVM processor count is four, IO parallelism eight, and Skia resource cache is 32 MiB per graphics context. These are component budgets, not a cap on total process memory.
- Playhead updates no longer recompose the whole application. Transport controls still receive live positions; shortcuts read the current engine position.
- The audio worker blocks on a command signal while idle/paused instead of polling every 20 ms, and always closes native resources on exit.
- Spectrum analysis requires visible subscribers, an enabled visualizer and fresh audio. Stopped audio decays to exact silence, then waits without a timer. Hidden/minimized windows suspend Canvas decoders and decorative motion.
- Home/Library folder and sign-in cards use static gradient artwork. JFR identified their continuous blurred gradients as a persistent GPU-render trigger while paused. Interactive feedback and glass styling remain.
- YouTube/BotGuard initialization is deferred to use, including session changes. Idle BotGuard engines release their page after 60 seconds. The party client/server initialize when the feature is opened or used.
- FFmpeg option dictionaries, partially opened codecs and pointer arrays are freed. Canvas frames no longer take the extra byte-array/Image conversion path. Frame pixel ownership is regression-tested.
- Disk-cache paths are derived directly rather than retained indefinitely in a URL-to-path map.

Cold feature initialization is now paid on first use rather than at application startup. Windows/macOS memory usage and prolonged online/Canvas sessions still need separate measurements.

## Validation and reproduction

Local validation passed: **514 tests** (107 shared, 42 desktop UI, 365 desktop app), with no failures or skips. New regressions cover playhead state isolation, native frame pixel ownership and spectrum decay.

Run from a desktop-session terminal so the GUI environment is inherited:

```sh
rtk nix shell nixpkgs#jdk21 --command env LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu ./gradlew :shared:jvmTest :desktopUi:jvmTest :desktopApp:test :desktopApp:createDistributable :desktopApp:packageDeb -Pbitchord.version=1.4.0-beta-0

rtk nix shell nixpkgs#jdk21 --command env LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu python3 scripts/profile-desktop.py /opt/bitmusic --output /tmp/bitmusic-baseline.json

rtk nix shell nixpkgs#jdk21 --command env LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu python3 scripts/profile-desktop.py desktopApp/build/compose/binaries/main/app/BitMusic --output /tmp/bitmusic-beta.json
```

The script records jar SHA-256 fingerprints, validates actual local playback, and removes its own temporary profile. Keep `--time-scale` identical between compared runs; the default is 1.0.

Cache API reference: [Coil image loader configuration](https://coil-kt.github.io/coil/image_loaders/).
